# 📁 Fayllar joylashuvi — Qo'llanma

Bu papkaga loyiha rasmlarini, prezentatsiyani va boshqa fayllarni joylashtiring.

## Jamoa fotosurasi
```
public/images/team-photo.jpg
```
> Barcha 4 a'zo bilan birga tushgan rasm. Tavsiya: 1200×800px yoki undan katta.

## A'zolar portretlari
```
public/images/member-1.jpg   ← 1-a'zo
public/images/member-2.jpg   ← 2-a'zo
public/images/member-3.jpg   ← 3-a'zo
public/images/member-4.jpg   ← 4-a'zo
```
> Tavsiya: kvadrat format 400×400px yoki 600×600px.

## Loyiha rasmi (About bo'limi)
```
public/images/project-photo.jpg
```
> Loyiha jarayoni yoki natijasini ko'rsatuvchi rasm.

## Prezentatsiya fayli
```
public/files/presentation.pdf
```
> PDF faylini shu yerga ko'chiring. Sayt avtomatik ravishda tekshiradi.

## Galereya rasmlar
```
public/images/gallery/photo-1.jpg
public/images/gallery/photo-2.jpg
...
```
> Galereya elementlarini src/data/siteData.js faylining gallery.items bo'limiga qo'shing.

## Slayd ko'rinishlari (ixtiyoriy)
```
public/images/slides/slide-1.jpg
public/images/slides/slide-2.jpg
...
```
> Slaydlarni src/data/siteData.js faylining presentation.slides bo'limiga qo'shing.

---

## Barcha ma'lumotlarni tahrirlash
Barcha matn, ismlar, kontakt va yo'llar faqat bitta faylda:
```
src/data/siteData.js
```
